# Software installation requests

Approved software is available in the Self-Service portal and installs without admin rights.

## Software not in Self-Service
Raise a software request ticket with the software name, version, business reason and your manager's name. Security reviews new software within 3 business days. Do not install unapproved software, browser extensions or AI coding assistants on company devices.

## Licences
Paid licences (for example IDEs or design tools) need manager approval in the ticket.
